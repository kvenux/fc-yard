# Generated controller assets

Generated with the built-in imagegen tool. Transparent PNG originals copied into this workspace. HTML overlays render changing probabilities; probability text is not baked into the textures.

## dpad

Use case: product-mockup. Asset type: transparent web UI button texture. Generate one single classic 1980s Famicom / NES controller black cross-shaped D-pad, orthographic straight top-down view, perfectly symmetrical plus shape. Black subtly textured molded ABS plastic, softly beveled edges, shallow molded directional arrow on outer tip of each of four arms. Large blank flat areas on each arm for a separately rendered probability number. Center is a flat blank square. The cross occupies 92 percent of a square image, centered with equal margins. Authentic utilitarian old game controller hardware, slight warm studio highlight from upper left. Isolated on genuinely transparent background. No controller body, no hand, no letters, no numbers, no labels, no extra objects, no neon, no perspective tilt. All four arms equal width one third of cross total width. Premium sharp product rendering for use at small UI sizes.

## fire

Use case: product-mockup. Asset type: transparent web UI button texture. Generate one single classic 1980s Japanese Famicom controller round crimson red action button, orthographic straight top-down, centered occupying 92 percent of a square image with equal margins. Authentic red molded ABS plastic, subtle fine material grain, soft rounded bevel rim, concave flat central face, realistic slight sidewall and soft light upper left. Central face completely blank to overlay a live probability number and an A label in HTML. Small charcoal mounting ring tightly around red circle, no housing. Isolated genuinely transparent background. No text, no numbers, no hand, no extra buttons, no neon, no tilted perspective. Matches a black classic cross D-pad, premium realistic game hardware UI asset.
